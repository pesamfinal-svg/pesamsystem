> Analiza projektu na podstawie kodu źródłowego. Projekt to system zarządzania **magazynem resztek budowlanych i flotą pojazdów** dla firmy budowlanej, oparty o Next.js 16 + Firebase + Google Vertex AI (Gemini).

## 📸 1. „Zapytaj AI" — Rozpoznawanie materiałów z aparatu

Twój pomysł #1 — **przycisk „🤖 Zapytaj AI" przy każdej pozycji na placu.**

### Jak to działa
```
[Użytkownik robi zdjęcie] → Gemini Vision (gemini-2.5-flash)
→ rozpoznaje materiał budowlany
→ sugeruje nazwę, kategorię, jednostkę miary
→ opcjonalnie: proponuje dopasowanie do istniejącej pozycji w magazynie
```

### Endpoint do stworzenia
**`POST /api/ai-identify-material`**

```typescript
// Payload wejściowy
{ imageBase64: string; hint?: string }

// Odpowiedź
{
  name: string;          // "Bloczek betonowy 590x120x239"
  category: string;      // "pustaki"
  unit: string;          // "szt."
  confidence: number;    // 0.92
  description: string;   // "Bloczek termoizolacyjny, seria Pro..."
  matchedItemId?: string; // ID istniejącej pozycji w Firebase
}
```

### UI — gdzie dodać przycisk
W [`plac/resztki/page.tsx`](file:///c:/Users/admin/Desktop/pesam-system/src/app/plac/resztki/page.tsx) — na każdej karcie pozycji (obok „ZRÓB FOTO"):

```
[🤖 Zapytaj AI]  ←  nowy przycisk, żółty/pomarańczowy
```

> [!TIP]
> Gemini `gemini-2.5-flash` doskonale rozpoznaje materiały budowlane ze zdjęć. Możesz przekazać mu też kontekst: *„Jesteśmy hurtownią materiałów budowlanych, rozpoznaj co to za materiał"*.

Twój pomysł #2 — **zakładka ustawień poziomu zapełnienia stref z suwakiem.**

**Komponent HTML range slider:**
```html
<input type="range" min="0" max={zone.totalCapacity}
  value={zone.currentOccupied}
```

> Po zmianie suwaka → `updateDoc` do Firebase → automatyczny alert AI gdy strefa > 80% pojemności (już masz endpoint `warehouse-capacity-alert`!).

## 🏗️ Architektura „Scan & Identify" — szczegóły implementacji

```mermaid
sequenceDiagram
    participant U as 📱 Użytkownik (plac)
    participant App as PWA (resztki/page.tsx)
    participant API as /api/ai-identify-material
    participant G as Gemini 2.5 Flash
    participant DB as Firebase Firestore

    U->>App: Klik 🤖 przy pozycji "Big Bag"
    App->>U: Otwórz kamerę (input[capture])
    U->>App: Zrób zdjęcie
    App->>API: POST {imageBase64, currentItems[]}
    API->>G: "Co to za materiał budowlany?"
    G-->>API: {name, category, unit, confidence}
    API->>DB: Szukaj podobnej pozycji
    DB-->>API: matchedItem (opcjonalnie)
    API-->>App: Wynik identyfikacji
    App->>U: Modal z wynikiem + "Dodaj do magazynu?"
```
